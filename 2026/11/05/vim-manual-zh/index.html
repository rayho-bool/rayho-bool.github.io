开始之前

Vim 是一个极其强大的编辑器，命令多到任何一本教程都写不完。这份手册只挑出最必需的那部分——刚好够你把它当作一个通用编辑器顺手地用起来。

本教程是为「用」而设计的。你必须真的敲下这些命令，才能学会它们；只是把文字读一遍，合上页面就会忘光。

注意
课程中的命令会修改文本。请先复制一份文件用来练手，别拿重要文件做实验。

开始前的三条约定

  1. 确认 Caps Lock（大写锁定）是关闭的。 Vim 区分大小写，u 是撤销，U 是整行还原，完全两回事。
  2. 先练 h j k l，别急着用方向键。 方向键也能动，但手要离开主键区；熟悉之后 hjkl 快得多。
  3. 随时可以按 Esc 逃出来。 不知道自己在什么状态、输错了半个命令——按 Esc 回到普通模式，重来就行。

第 1 章 活下来：移动、退出、改字

先学会三件事——怎么动、怎么跑、怎么改一个字。

1.1 移动光标 h j k l

用 h j k l 四个键移动光标，位置排布正好对应方向：

h 在主键区最左边，所以向左；l 在最右边，所以向右；j 的尾巴朝下，像个下箭头。

动手做

  1. 在屏幕上随便移动，直到手感自然。
  2. 按住 j 不放，直到它开始自动重复——这就是去下一课的方式。
  3. 用 j 移动到 1.2 课。

提示
不确定自己敲了什么？按 Esc 回到普通模式，重新输入想要的命令即可。

1.2 退出 Vim :q!

先读完再动手
执行下面步骤之前，请先把整节课读完。

  1. 按 Esc，确保处在普通模式。
  2. 输入 :q! 然后回车 —— 退出编辑器，丢弃所有修改。
  3. 要回来，重新执行当初进入教程的命令：vimtutor 回车。
  4. 如果已经记住了，就完整做一遍第 1–3 步：退出，再进来。

:q! 的意思是「退出且不保存」。保存的办法在 1.6 课。

1.3 删除字符 x

把光标放到要删的字符上，按 x，它就消失了。

  1. 把光标移到下面标着 ---> 的那一行。
  2. 移动到错字上。
  3. 按 x 删除多余的字符。
  4. 重复第 2–3 步，直到句子正确。

练习文本

顺带记住一条学习原则：不要背命令，边用边记。

1.4 插入文本 i

按 i 进入插入模式，输入的文字会插在光标之前。

  1. 光标移到第一条 ---> 行。
  2. 把光标放到「要插入内容紧跟着的那个字符」上。
  3. 按 i，输入缺少的内容。
  4. 每改完一处按 Esc 回到普通模式；重复直到两句一致。

练习文本

1.5 行尾追加 A

按大写 A，光标直接跳到行尾并进入插入模式——补全一句话最省事的办法。

  1. 光标移到第一条 ---> 行（停在哪一列都无所谓）。
  2. 按 A，输入缺少的内容。
  3. 按 Esc 回到普通模式。
  4. 移到第二条 ---> 行，重复上面两步。

练习文本

1.6 保存并退出 :wq

先读完再动手
下面这些步骤会离开当前文件，请先看完整节课。

  1. 像 1.2 课那样退出教程：:q!。或者，如果你还有另一个终端，就在那边操作。
  2. 在 shell 提示符下输入 vim tutor 回车。vim 是启动编辑器的命令，tutor 是要编辑的文件名——请用一个可以随便改的文件。
  3. 用刚学的命令插入、删除一些文字。
  4. 用 :wq 回车保存并退出。
  5. 如果第 1 步已经退出了 vimtutor，就重新启动它，往下翻到本章小结。
  6. 理解之后，真的去做一遍。

第 1 章小结

  • 移动光标：方向键或 h（左）j（下）k（上）l（右）。
  • 启动：vim 文件名 回车。
  • 退出：Esc :q! 回车（丢弃修改）；或 Esc :wq 回车（保存修改）。
  • 删除光标处字符：x。
  • 插入：i 在光标前插入；A 在行尾追加。
  • 按 Esc 回到普通模式，也能取消一个输了一半的命令。

第 2 章 删除与撤销

本章藏着 Vim 最核心的思想：操作符 + 动作。

2.1 删除一个单词 dw

  1. 按 Esc 确保在普通模式。
  2. 光标移到标着 ---> 的行。
  3. 把光标放到要删单词的开头。
  4. 输入 dw，这个单词就消失了。

提示
敲下 d 之后，屏幕最后一行会显示这个字母——Vim 正在等你输入后面的 w。如果看到的不是 d，说明敲错了，按 Esc 重新开始。

练习文本

2.2 删到行尾 d$

  1. 按 Esc。
  2. 光标移到标着 ---> 的行。
  3. 把光标移到正确内容的末尾（第一个句号之后）。
  4. 输入 d$，从光标一直删到行尾。

练习文本

2.3 操作符与动作 operator + motion

许多修改类命令都是由「操作符」和「动作」两部分拼成的。以删除操作符 d 为例，格式是：

  • d —— 操作符（operator），表示「删除」。
  • 动作（motion） —— 表示这段操作作用到哪儿。

常见的动作：

动作 含义
w 到下一个单词的开头，不含该单词首字符
e 到当前单词的结尾，包含最后一个字符
$ 到行尾，包含最后一个字符

所以 de = 从光标删到当前单词结尾。

提示
在普通模式下，只按动作不按操作符，效果就是移动光标——动作本身就是一次移动。

2.4 给动作加次数 2w 3e 0

在动作前面加一个数字，它就会重复那么多次。

  1. 光标移到标着 ---> 的行首。
  2. 输入 2w，光标前进两个单词。
  3. 输入 3e，光标到再往后第三个单词的词尾。
  4. 输入 0（数字零），回到行首。
  5. 换几个数字重复第 2、3 步。

练习文本

2.5 计数也能用在删除上 d2w

在「操作符 + 动作」中间插入数字，就能一次删掉更多：

  1. 光标移到标着 ---> 的行，放在第一个全大写单词上。
  2. 输入 d2w，删掉这两个大写单词。
  3. 换个数字，重复练习。

练习文本

2.6 整行操作 dd 2dd

整行删除太常用了，所以 Vi 的设计者干脆让你连按两个 d。

  1. 光标移到下面诗句的第二行。
  2. 输入 dd，整行消失。
  3. 再移到第四行。
  4. 输入 2dd，一次删两行。

练习文本

2.7 撤销 u U Ctrl-R

  1. 光标移到标着 ---> 的行，停在第一个错误上。
  2. 按 x 删掉第一个多余字符。
  3. 按 u 撤销刚才的命令。
  4. 这次用 x 把这一行的错误全改对。
  5. 按大写 U，整行恢复成最初的样子。
  6. 多按几次 u，把 U 和之前的命令一个个撤掉。
  7. 按 Ctrl-R 几次，重做（撤销「撤销」）。

练习文本

第 2 章小结

  • 删到下一个单词：dw；删到行尾：d$；删整行：dd。
  • 给动作加次数即重复：2w。
  • 修改类命令的格式：操作符 [次数] 动作。操作符如 d，次数可选，动作如 w、$。
  • 回行首：0（数字零）。
  • 撤销：u；整行还原：U；重做：Ctrl-R。

第 3 章 粘贴 · 替换 · 修改

删掉的东西没丢，它在寄存器里等你捡回来。

3.1 粘贴 p

  1. 光标移到第一条 ---> 行。
  2. 按 dd 删掉整行——它被存进了 Vim 的寄存器。
  3. 光标移到 c) 那一行，也就是这一行应该放到的位置之上。
  4. 按 p，被删的行会出现在光标所在行的下方。
  5. 重复第 2–4 步，把四行排回正确顺序。

练习文本

3.2 替换单个字符 r

  1. 光标移到第一条 ---> 行。
  2. 把光标停到第一个错误上。
  3. 按 r，再按正确的那个字符。
  4. 重复，直到第一行和第二行完全一样。

练习文本

3.3 修改操作符 ce

c 是「修改」操作符：删掉目标，然后直接进入插入模式。

  1. 光标移到第一条 ---> 行。
  2. 把光标放在 lubw 的 u 上。
  3. 输入 ce，然后输入正确的词（这里是 ine）。
  4. 按 Esc，移到下一个要改的字符。
  5. 重复，直到两句一致。

练习文本

注意：ce 会删掉整个单词，并把你留在插入模式里。

3.4 更多改法 c$

修改操作符配的动作，和删除完全一样：

动作同样可以是 w（单词）、$（行尾）等等。

  1. 光标移到第一条 ---> 行。
  2. 移到第一个要改的地方。
  3. 输入 c$，照着第二行把这一行剩下的部分打完，再按 Esc。

练习文本

提示
插入模式下打错了字，可以直接用 Backspace 退格修改。

第 3 章小结

  • p 把刚删掉的文本放回光标之后（删的是整行，就落在光标所在行的下面）。
  • r + 新字符：替换光标下的那一个字符。
  • c 从光标改到动作指定处，如 ce、c$。
  • 修改的格式：c [次数] 动作。

第 4 章 定位 · 搜索 · 替换

在大文件里瞬间跳到你想要的地方。

4.1 位置与文件状态 Ctrl-G G gg

  1. 按住 Ctrl 再按 g（写作 Ctrl-G）。屏幕底部会显示文件名和你当前所在的行号——记住这个行号，第 3 步要用。
  2. 按 G 跳到文件末尾；输入 gg 回到文件开头。
  3. 输入刚才记下的行号，再按 G，就回到原来的位置。
  4. 有把握的话，把 1–3 步完整做一遍。

提示
如果设置过 'ruler' 选项，光标位置也会一直显示在屏幕右下角（见 :help 'ruler'）。

4.2 搜索 / ? n N

  1. 在普通模式下按 /，它和光标会出现在屏幕底部，就像 : 命令一样。
  2. 输入 errroor 回车——这就是你要找的词。
  3. 再找同一个词，按 n；反方向找，按 N。
  4. 想向上搜索，用 ? 代替 /。
  5. 按 Ctrl-O 回到上一个位置，连按可以一直往回；Ctrl-I 则向前。

练习文本

提示
搜索到文件末尾后会从开头继续绕回来——除非 'wrapscan' 选项被关掉了。

4.3 括号匹配 %

  1. 把光标放到标着 ---> 那一行里任意一个 (、[ 或 { 上。
  2. 按 %。
  3. 光标会跳到与之配对的括号上。
  4. 再按 %，又跳回原来那个。
  5. 换一个括号试试，看看 % 的行为。

练习文本

排查括号不匹配的代码时，这个键非常有用。

4.4 替换 :s/old/new/g

  1. 光标移到标着 ---> 的行。
  2. 输入 :s/thee/the 回车。注意：它只改这一行里第一个 thee。
  3. 再输入 :s/thee/the/g。加上 g 标志表示「整行全局」，这一行里所有 thee 都会被替换。

练习文本

替换的几种范围写法：

命令 作用范围
:#,#s/old/new/g 第 # 行到第 # 行之间
:%s/old/new/g 整个文件
:%s/old/new/gc 整个文件，每次替换前都问你一句

第 4 章小结

  • Ctrl-G 显示位置与文件状态；G 到末尾；数字 G 到指定行；gg 到开头。
  • / 向前搜索，? 向后搜索，n 同向重复，N 反向重复；Ctrl-O 回旧位置，Ctrl-I 去新位置。
  • 光标停在括号上按 %，跳到配对的括号。
  • 替换：:s/old/new（首个）、:s/old/new/g（整行）、:#,#s/old/new/g（区间）、:%s/old/new/g（全文）、加 c 逐个确认。

第 5 章 外部命令与文件读写

Vim 不只是编辑器，它还是你的 shell 前端。

5.1 执行外部命令 :!

  1. 按 :，光标落到屏幕底部，可以输入命令行命令了。
  2. 再输入 !（感叹号），表示接下来要执行一条外部 shell 命令。
  3. 例如输入 ls 后回车，就会列出目录内容，和在 shell 里一模一样。Windows 上如果 ls 用不了，改用 :!dir。

提示
任何外部命令都能这样执行，也可以带参数。另外：所有 : 开头的命令都要按回车才算数——后面不再每次都提醒了。

5.2 另存为 :w FILENAME

  1. 输入 :!dir 或 :!ls 看看目录里有什么。
  2. 挑一个还不存在的文件名，比如 TEST。
  3. 输入 :w TEST 回车。
  4. 整个文件（包括这份教程）就被存成了 TEST。再用 :!dir / :!ls 确认一下。

如果用 vim TEST 重新打开它，内容就是你保存那一刻的精确副本。

练完把它删掉：Windows 用 :!del TEST，Unix 用 :!rm TEST。

5.3 只保存选中的部分 v motion :w

  1. 把光标放到这一行。
  2. 按 v 进入可视模式，把光标移到下面第五项——能看到文本被高亮选中。
  3. 按 :，屏幕底部会出现 :'<,'>。
  4. 接着输入 w TEST（TEST 是一个尚不存在的文件名），回车前确认整行显示为 :'<,'>w TEST。
  5. Vim 会把选中的行写进 TEST。用 :!dir / :!ls 看一眼，但先别删——下一课还要用。

提示
v 开启可视选择，移动光标可以放大或缩小选区，然后可以接操作符处理这段文字，比如 d 删除。

5.4 读入并合并文件 :r FILENAME

  1. 把光标放到这一行上面。
  2. 输入 :r TEST 回车。文件内容会插入到光标所在行的下方。
  3. 往上翻，你会看到 5.3 课出现了两份：原文和读进来的副本。

提示
也能读入外部命令的输出，例如 :r !ls 会把 ls 的结果放在光标下面。

第 5 章小结

  • :!command 执行外部命令。跨平台对照：:!dir / :!ls 列目录；:!del F / :!rm F 删文件。
  • :w FILENAME 把当前文件另存为 FILENAME。
  • v 选中若干行后 :w FILENAME，只保存选中的部分。
  • :r FILENAME 把磁盘文件读入到光标下方。
  • :r !dir 把命令输出读入到光标下方。

第 6 章 插入 · 复制 · 选项

补齐插入的几种姿势，学会复制粘贴，顺手改两个常用设置。

6.1 开新行 o O

  1. 光标移到第一条 ---> 行。
  2. 按小写 o，在光标所在行下方新开一行，并进入插入模式。
  3. 输入一些文字，按 Esc 退出插入模式。
  4. 按大写 O，则在上方开新行。在第二条 ---> 行上试试。

练习文本

6.2 光标之后追加 a

  1. 光标移到第一条 ---> 行的行首。
  2. 按 e，直到光标停在 li 的末尾。
  3. 按小写 a，在光标之后插入。
  4. 把单词补全成下一行的样子，按 Esc。
  5. 用 e 跳到下一个没写完的词，重复。

练习文本

提示
a、i、A 都进入同一个插入模式，区别只在插入位置：i 光标前、a 光标后、A 行尾。

6.3 替换模式 R

  1. 光标移到第一条 ---> 行，停在第一个 xxx 的开头。
  2. 按大写 R，输入下面第二行对应的数字，逐字覆盖掉 xxx。
  3. 按 Esc 退出替换模式。注意这一行其余部分没有被改动。
  4. 重复，替换剩下的 xxx。

练习文本

替换模式和插入模式很像，只不过每敲一个字符都会覆盖掉一个已有字符。

6.4 复制与粘贴 y p

  1. 光标移到标着 ---> 的行，停在 a) 之后。
  2. 按 v 进入可视模式，把光标移到 first 之前。
  3. 按 y 复制（yank）高亮的部分。
  4. 把光标移到下一行末尾：j$。
  5. 按 p 粘贴，然后输入 a → second → Esc。
  6. 再用可视模式选中 item.，y 复制，j$ 到行尾，p 粘贴。

练习文本

提示
y 也能当操作符用：yw 复制一个单词。

6.5 设置选项 :set

  1. 输入 /ignore 回车搜索，多按几次 n 看看结果。
  2. 输入 :set ic（ignorecase），让搜索忽略大小写。
  3. 再按 n 搜索，会发现 Ignore、IGNORE 也被找到了。
  4. 输入 :set hls is，同时开启高亮和增量搜索。
  5. 再搜一次 /ignore 回车，观察区别。
  6. 输入 :set noic 关闭忽略大小写。

提示
取消匹配高亮：:nohlsearch。只让一次搜索忽略大小写：在搜索词里加 \c，如 /ignore\c。

第 6 章小结

  • o 在下方开新行，O 在上方开新行。
  • a 在光标后插入，A 在行尾插入。
  • e 移动到单词末尾。
  • y 复制，p 粘贴。
  • 大写 R 进入替换模式，直到按 Esc。
  • :set xxx 设置选项：ic/ignorecase 忽略大小写、is/incsearch 增量搜索、hls/hlsearch 高亮匹配；长短名都行。
  • 选项名前加 no 表示关闭：:set noic。

第 7 章 帮助与配置

真正的 Vim 用法只有一句：学会查 help。

7.1 使用在线帮助 :help

Vim 自带一套完整的在线帮助。打开方式三选一：

  • 按 HELP 键（如果你的键盘有）
  • 按 F1
  • 输入 :help 回车

读一读帮助窗口里的文字，就能明白它怎么用：

  • Ctrl-W Ctrl-W：在窗口之间跳转
  • :q 回车：关闭帮助窗口

给 :help 加参数，几乎能查到任何主题：

7.2 创建启动脚本 vimrc

Vim 比 Vi 多出很多功能，但大部分默认是关闭的。想要它们，得先建一个 vimrc 文件。

  1. 打开 vimrc（路径取决于系统）：
  1. 读入官方示例配置：:r $VIMRUNTIME/vimrc_example.vim
  2. 用 :w 保存。

下次启动 Vim 就会有语法高亮。你也可以把喜欢的设置都加进这个文件。更多信息：:help vimrc-intro。

7.3 命令行补全 Ctrl-D Tab

  1. 确认没有运行在兼容模式：:set nocp。
  2. 看看目录里有什么文件：:!ls 或 :!dir。
  3. 输入命令的开头：:e。
  4. 按 Ctrl-D，Vim 会列出所有以 e 开头的命令。
  5. 输入 d 然后 Tab，命令名自动补全为 :edit。
  6. 加一个空格，再输入已有文件名的开头：:edit FIL。
  7. 按 Tab，文件名会被补全（前提是唯一）。

提示
补全对很多命令都有效，随手试试 Ctrl-D 和 Tab；在 :help 里尤其好用。

第 7 章小结

  • :help 或 F1 打开帮助窗口；:help cmd 查具体命令。
  • Ctrl-W Ctrl-W 切换窗口，:q 关闭帮助窗口。
  • 建一个 vimrc 启动脚本，保存你常用的设置。
  • 输入 : 命令时按 Ctrl-D 看候选项，按 Tab 采用补全。

附录 B 五种模式

Vim 的一切「怪」，都源于它是模式化的编辑器。

模式 说明
Normal 普通 默认模式。按键是指令，不是文字。一切从这里出发，也回到这里。
Insert 插入 按 i a A o O 进入，敲什么就写什么。
Visual 可视 按 v 选中文本，再交给操作符处理（d 删、y 复制）。
Replace 替换 按 R 进入，逐字覆盖原文。
Command-line 命令行 按 : / ? 进入，在屏幕底部输入。

记住一句话就够了：不确定自己在哪儿，就按 Esc。

所有 : 命令都要回车才生效；所有 : 命令都可以用 Esc 取消。

附录 C 常见坑与练习建议

新手最常踩的五个坑

  1. 忘了自己在插入模式。 在插入模式里按 h j k l，会直接打出这几个字母。先按 Esc。
  2. 把 :q 当成万能退出。 有未保存的修改时它不会退出，只会抱怨。要么 :wq 保存，要么 :q! 放弃。
  3. 开了大写锁定。 u 变 U、o 变 O，行为完全不同。
  4. 用方向键或鼠标。 能凑合，但会拖慢你建立肌肉记忆的速度。前两周刻意用 hjkl。
  5. 想一次背完所有命令。 不要。记住 10 个常用命令，剩下的在用到时查 :help。

练法

  • 每天 15 分钟，连续一周，比一次性看完两小时有效得多。
  • 关掉方向键（把 noremap <Up> <Nop> 写进 vimrc），逼自己用 hjkl。
  • 在真项目里用。改配置文件、写 commit message，都开 Vim。
  • 一次只加一个新习惯：这周练 dw，下周练 ciw，别贪多。

一条捷径
把「操作符 + 动作」当成一门语法来学：d（删）、c（改）、y（复制）是动词，w、e、$、0、i(、a" 是名词。动词乘名词，组合数是几十上百个命令，你只需要记 3 + 6 个零件。

附录 D 结语与延伸

到这里，Vim 教程就结束了。它只给了你一个简要的概览——刚好够你比较顺手地使用这个编辑器。它远不完整，因为 Vim 还有多得多的命令。接下来该读用户手册了：:help user-manual。

推荐读物

  • Vim - Vi Improved，Steve Oualline 著，New Riders 出版。
    第一本完全讲 Vim 的书，对初学者尤其友好，例子和图都很多。
  • Learning the Vi Editor，Linda Lamb 著，O’Reilly & Associates 出版。
    更老一些，讲的更多是 Vi，但依然值得推荐；第六版也包含 Vim 的内容。
